# C++ Yearly Calendar Generator

A console-based C++ application that generates a beautifully formatted full-year calendar. By simply entering a year, the program calculates the exact day of the week for the 1st of every month and prints all 12 months in a structured grid.

## 🎮 Features
- Full Year Output: Prints all 12 months of the entered year.
- Accurate Day Calculation: Uses a mathematical algorithm to determine the starting day of the week for any given month and year.
- Leap Year Support: Automatically detects leap years to correctly display 29 days for February.
- Input Validation: Ensures the user enters a valid year (greater than 0).

## 🛠️ Technical Details
- Implements a date algorithm to calculate the day of the week.
- Uses arrays to store month names, day names, and the number of days in each month.
- Formats the output neatly using printf for precise spacing and alignment.

## 🚀 How to Run
1. Clone this repository or download it as a ZIP file.
2. Open the .sln file in Visual Studio.
3. Press F5 or Ctrl + F5 to build and run the program.
4. Enter a year (e.g., 2024) to see its full calendar.
